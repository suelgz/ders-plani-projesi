# Ders Planım

Web Geliştirme JavaScript eğitimi için hazırladığım basit bir görev takip uygulaması.

HTML, CSS, JavaScript, jQuery ve LocalStorage kullandım.

## Özellikler
- Görev ekleme: Başlık, ders, tarih ve öncelik
- Görevleri listeleme ve filtreleme
- Görev bilgilerini güncelleme veya tamamlandı işaretleme
- Görev silme
- Tarayıcıda LocalStorage ile kayıtları koruma

## Çalıştırma
`index.html` dosyasını tarayıcıda açmak yeterli. jQuery CDN üzerinden yüklendiği için internet bağlantısı gerekir.

## Canlı site
Vercel üzerinde yayınlanacaktır.

## Ekran görüntüsü
Projenin masaüstü ve mobil ekran görüntüleri teslim dosyasında yer alır.
